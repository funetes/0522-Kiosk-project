1. 기본 앱 ai 로 생성
2. 모델 과 유틸기능을 별로도 분리
3. controller에 합쳐져 있던 ui 생성 + 컨트롤 + 로직 에서 viewModel 추가해서 로직 분리
4. 라인 별 주석 추가
5. CafeKioskController 에서 ui생성 코드 별도 클래스로 분리
6. 관리자 정산 기능
7. 쿠폰 or 포인트 적립 기능
8. 매장or포장 선택 후 영수증 출력 후 다음 화면에서 이전으로 돌아가기
9. 음료 가 Ade 인 경우 Hot 버튼이 안나오도록 처리
